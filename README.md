# Number Hub website

Static multi-page website for GitHub Pages.

## Files
- `index.html` — homepage and game overview
- `privacy.html` — privacy policy starter template
- `support.html` — support/contact page
- `terms.html` — terms of use starter template

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `number-hub-website`).
2. Upload all four HTML files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your site URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

All CSS is embedded in each HTML page. Header and footer markup is repeated on every page, and links use relative paths so the site works from a GitHub Pages project URL.

## Before publishing
Search for `[YOUR-SUPPORT-EMAIL]`, `[DEVELOPER / COMPANY NAME]`, `[ADD DATE]`, and other square-bracket placeholders. Replace them with accurate details. In particular, complete the privacy policy to reflect the exact data collected by your app and every advertising, analytics, crash-reporting, and other SDK you include. Do not publish the privacy policy as-is.
